# Code of Conduct

## Our Standard

This project expects respectful, constructive, and professional behavior.
By participating, you agree to help keep this repository welcoming and
useful for everyone.

Examples of expected behavior:

- Be respectful in discussions, issues, and pull requests.
- Give technical feedback clearly and without personal attacks.
- Assume good intent, but be direct about problems in code or process.
- Respect different levels of experience and backgrounds.
- Keep collaboration focused on improving the project.

Examples of unacceptable behavior:

- Harassment, hate speech, discrimination, or intimidation.
- Personal insults, trolling, or repeated hostile behavior.
- Publishing private information without permission.
- Spam, misleading claims, or intentionally disruptive conduct.
- Taking credit for work you did not create.

## Attribution and Respect for Work

This repository is free to use under the included license, but users
must give credit to the original author where required by that license.
Do not remove author attribution from the licensed work.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues,
pull requests, commits, or other contributions that violate this code
of conduct.

Repeated or serious violations may result in temporary or permanent
restriction from participating in the project.

## Reporting

If you experience or observe unacceptable behavior, contact the project
maintainer through the repository owner account on GitHub.

## Scope

This code of conduct applies to:

- GitHub issues
- pull requests
- discussions
- commit messages
- project-related communication tied to this repository
